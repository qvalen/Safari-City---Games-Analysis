# Safari City – Early Player Journey Analysis

This project analyzes the first few levels of **Safari City**, a mobile city-building game. The goal is to understand **how new players experience the game**, identify where they drop off, and suggest improvements to keep them engaged.

## What’s in this project

1. Early Player Journey Funnel
   - Tracks players from installation through levels 1–10  
   - Identifies friction points like confusing tutorials, unclear goals, and weak feedback  

2. Player Segmentation  
   - Groups players based on behavior and motivation: casual, achievement-focused, creative, social, progression-focused, or likely to drop off  
   - Helps design better onboarding, rewards, and in-game events  

3. Data Analysis & Recommendation  
   - Shows engagement trends over 1, 7, and 30 days  
   - Suggests improvements like better tutorials, milestone rewards, and personalized notifications  

## Key Insights

- Many players leave the game in the first few levels due to unclear instructions and weak rewards.  
- A small group of loyal players stays active for 30 days.  
- Improving onboarding, storytelling, and rewards could increase retention by 20–30%.


## Goal
Help the game team **understand new players** and make the first levels more engaging, fun, and rewarding.
